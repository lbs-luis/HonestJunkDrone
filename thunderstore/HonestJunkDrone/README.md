# HonestJunkDrone

With the Artifact of Command enabled, the items the Junk Drone prints come out as Command Cubes: you have to pick one of several random options instead of getting the item the drone printed. HonestJunkDrone makes the Junk Drone drop the item it printed, as a regular pickup on the ground.

## What it changes

- Items printed by a Junk Drone are never wrapped in a Command Cube, even when the Artifact of Command is enabled.
- Printed items fall to the ground as normal pickups, the same as without the artifact.
- Other Command Cubes (chests, shrines, and so on) work as before.

## Dependencies

Your mod manager installs these automatically:

- BepInExPack
- HookGenPatcher
